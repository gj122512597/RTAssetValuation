Pricing Engine

定价模型：Hedonic 对数线性回归 + SHAP

系统刻意采用可解释的 Hedonic 特征价格法，而非黑盒 AI——每个系数都能审计，核价人员能清楚说出"租金高是因为地铁近"。

两种定价方法（本质都是 Hedonic）
市场比较法 · comparative（12 维）

ln(租金)=β₀+β₁·地铁+β₂·房龄+… 周边竞品充足时适用，区间更窄（±12%）。

历史数据法 · historical（4 维）

只用自身历史成交 + 装修 + 免租，竞品稀少时适用，区间 ±16%。

前端推理 vs 后端训练
• 前端手写 JS 推理：估价页即时给预测值 + SHAP 贡献分解，零后端依赖。
• 后端独立推理 POST /api/models/predict：系数留服务端，只回预测值 + 贡献。
• 真实训练 fit_hedonic.py：岭回归 + LOO-CV，系数写回 hedonic_models。
• SHAP 5 字段：feature / feature_cn / contribution / explanation / source，均中英对照，合规审计用。
